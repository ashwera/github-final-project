# This is the README.md file for the **github-final-project**

A calculator for simple interest, given a principal amount, annual rate of interest, and time period in years.

## Input

- `p`: principal amount
- `t`: time period in years
- `r`: annual rate of interest

## Output

Simple interest = `p * t * r / 100`

Run `simple-interest.sh` and enter the principal, time period, and annual rate when prompted.
